# アンケート機能2：出席アンケート

2026-09-16実装。既存の `/survey` を「その他アンケート」、新設の `/survey/attendance` を「出席アンケート」として画面上部のタブで切り替える。既存アンケートの回答と独立して保存する。

## 利用方法

1. 選手一覧に在籍中の選手を登録する。この名簿が出席アンケートに表示される。
2. 管理者は回答者管理で本人用ログインを発行する。出席アンケート下部の「本人ログインと選手の紐付け」で、その回答者と選手を結び付ける。同名でも自動では紐付けない。
3. 対象月を選択して表示する。土日と祝日管理に登録された日を、重複を除いて日付順に表示する。祝日を自動取得する外部連携はなく、未登録の祝日は事前登録が必要。
4. 各日について○または△を選び、必要に応じて500文字以内のメモを入力して保存する。未回答は未選択で表示する。
5. 日ごとの「選手全員の回答」で在籍選手の回答・メモを確認できる。ログインユーザーのみ閲覧可能。

本人用ログインは紐付けた選手だけ回答できる。管理者のみ選手を選んで代理回答できる。共有編集者コードは閲覧のみ。削除済み選手は名簿と回答対象から除外し、既存回答はDBに保持する。選手の復元後は回答も再表示される。

1人の選手に複数の回答者を紐付けられない。削除済み回答者の紐付けも保持されるため、別の回答者へ変更するときは管理者が先に解除する。紐付け変更は次の回答時に適用される。

## 保存と移行

Flyway V2で `attendance_answers` と `survey_members.player_id` を追加する。既存の選手・アンケート・回答は変更しない。初回はDBをバックアップして `./gradlew.bat bootRun --args="--spring.flyway.enabled=true"` で起動する。ローカルMySQLには適用済み。

選手・日付の一意制約とバージョン検証で二重登録や古い画面からの上書きを防ぐ。不正な日付・回答値・長すぎるメモを拒否し、通常の入力エラーは内容を保持して戻る。競合時は画面を再読み込みして最新回答を確認する。

## 検証

既存テストに日付抽出、本人限定回答、管理者代理回答、紐付け権限・重複、入力検証、競合更新、生成HTMLの日付形式の検証を追加。計43件のテストとJARビルドを実行。ブラウザでもタブ遷移と月別回答欄を確認する。
