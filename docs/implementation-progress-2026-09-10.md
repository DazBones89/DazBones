# 実装状況（2026-09-10）

既存のレビュー資料は修正前の記録として保持しています。本資料が今回の対応状況です。

## 対応内容

- ログインコードを確認せず権限を付与するGET経路を削除。
- Spring SecurityによるURL単位の認可とCSRF保護を追加。ログイン成功時はセッションを作り直し、ログアウトはPOST化。
- 共有ログインコードとDB接続の秘密値をGit管理外のローカル設定へ移行。重複するアプリケーション設定を統合。
- お知らせ詳細も公開日時を確認し、公開前・存在しない記事はHTTP 404を返す。
- 活動予定・アンケートのJavaScriptと外部資産をレイアウトへ取り込まれるsection内に配置。
- 活動予定取得API、編集画面、更新・削除を実装。入力長・選択値・時間の前後関係を検証。
- カレンダーの日付範囲でオフセット付き日時を受け付け、範囲を最大93日に制限。
- 回答者管理のテンプレート参照を修正。写真ページの表示経路を追加（Instagram連携は未実装）。
- 選手のポジションを取得時に読み込み、一覧・編集の遅延読み込みエラーを修正。並び替え、1.000・未入力時の打率表示を修正。
- 部費の未払い人数を在籍者で集計し、トップ・部費画面の閲覧時に不足行を作成する処理を撤去。
- アンケート件数を在籍回答者に統一。無効回答者・不正回答値・非対象日・長すぎるコメントを拒否。
- アンケートで回答者変更時に既存回答を再取得し、未回答時の初期値・通信失敗表示・日付のUTC変換ずれを修正。
- 共通例外処理でHTTPステータスとAPIのJSONエラーを返し、一般例外の詳細は画面に出さずログへ記録。
- テスト用DBによる認証・権限・CSRF・描画・予定CRUD・選手更新・集計の回帰テストを追加。
