# 次段階の確定仕様

ユーザー確認済み。以下の実装に入る前に、前回までの修正をmainにコミットして区切りを作る。

## 確定事項

- 画像アップロード上限：5MBを維持。
- 選手成績：打率の分母となる入力項目を「打数」に統一。
- アンケート：代理回答は管理者のみ可能。アンケート作成と手動アンケート削除も管理者のみ可能。
- 部費：年会費として管理し、年度別履歴を保存。個人累計とチーム累計を表示。
- お知らせ：一般公開用と、ログインしたメンバー限定用の2区分を設ける。
- 管理者コード変更：変更後、既存のログインをすべて解除。
- 活動履歴：年度別ページを作る。

## あわせて進める修正

- 画像の実体検証、安全な差し替え、保存失敗時の旧画像保持と再入力。
- 選手・道具・部費の入力検証。
- 道具更新時の作成日時と削除済み所有者の扱い。
- 祝日CSVの全行検証と部分登録防止。
- 削除済み回答者の一覧・復元。
- アンケートの二重送信防止とエラー表示。
- 代替画像、未実装画面へのリンク、成功・失敗メッセージの整理。

## 実装時に具体化する点

以下は確定事項から必要になる設計上の論点で、未確定の仕様として扱う。

- 共有コードのログインと回答者本人の紐付け方法。名前選択だけでは代理回答制限を保証できない。
- 年度の開始月、個人・チーム累計を請求額・入金額のどちらで表示するか、過去の部費データの年度割当。
- 既存のお知らせの公開区分の移行方法。

この資料の追加時点では、上記機能の実装・DB変更は行っていない。
