# メンバー共有前の確認と運用

公開URL: https://dazbones.161-33-178-229.sslip.io/

## 共有するもの

- 公開URL
- 選手用ログインコード（master用は管理する本人だけが保管）
- メニュー → ログインからコードを入力すること
- 出欠確認で選手名と月を選び、○・△・×とコメントを入力すること
- 入力は自動保存されるため、保存完了表示を確認すること

選手コードを知る人は出欠回答だけでなく、部費・道具・選手情報なども
編集できます。以前合意した共通権限の仕様です。個人認証ではありません。
ログインコードはGitや公開のお知らせには載せず、メンバーだけに共有してください。

## 所有者が共有前に行うこと

1. 実際のスマートフォンでサイトを開き、選手用コードでログインする。
2. 正式な選手名簿を登録する（テスト名簿は初期化済み）。
3. 予定・部費・道具などの実データを必要に応じて入力する。
4. 写真の公開範囲と、メンバー向け案内の内容を確認する。

Instagram投稿は埋め込み先の状態やブラウザー設定により表示できない場合が
あります。その場合は「Instagramで投稿を開く」から確認できます。

## バックアップ

毎日午前4時（日本時間）にDBと写真を保存し、正常終了した直近7回を保持します。
整合性確保のため約1〜2分停止し、再ログインが必要になります。
サーバー停止などで実行できなかった場合、起動時に実行されます。

同じサーバー上のバックアップだけではサーバー消失に備えられません。
定期的に別の機器へコピーしてください。今回の復元確認用コピーは
ローカルのGit管理外 `backups/oracle-restore-check/` に保管しています。
バックアップには会員データとログインコードのハッシュが含まれるため非公開で保管します。

## サイトの修正

- データ変更：各管理画面から更新。
- コード変更：ローカルで修正・確認 → バックアップ → amd64イメージを作成 →
  サーバーへ転送 → アプリ更新 → HTTPSで動作確認。
- GitへのPUSHだけでは公開サーバーは更新されません。
- DBを変更する場合は既存データを保持する移行を追加し、復元方法も確認します。
